# D design alignment

The CareFlow Home screen now follows the selected **D. 스토리텔링·감성적** concept rather than a loose D+B reinterpretation.

Visible Home-screen contract:

- warm, airy horizontal navigation
- headline: `오늘도, 누군가의 마음이 조금 더 가벼워집니다.`
- story-led introduction for clinicians
- green `상담 시작하기 →` primary action
- secondary `서비스 소개 보기` action
- right-side warm chair/table/plant visual with `Listen / Understand / Care / Together`
- four floating cards: 정확한 전사 / 근거 기반 요약 / 사람의 검토 / 더 나은 변화

The focused dark workspace remains available after entering the consultation flow.
